---
name: dinsor-design
description: Build or edit UI (pages, components, styles) with the dinsor-design system: warm paper, one ink green accent, serif display, sans body. Use for any web UI work in a project that adopts dinsor-design.
---

1. Read `AGENTS.md` in the dinsor-design repo (or the copy in this project).
2. Start from `templates/page.html`. Copy markup from `components/`.
3. Use only tokens (`dist/tokens.md`). No hex, no gradients, no new radii or shadows.
4. Run `node scripts/lint.mjs <files>` and fix every line.
