Start

Getting started

Quill turns a folder of Markdown into a static site. Install it, point it at a folder, and build.

Install

Quill needs Node 20 or newer.

npm install --save-dev quill
npx quill build docs/

Output

The site is written to dist/. Serve it from any static host.

Configure

Put a quill.json next to your content. Every key is optional.

{
  "title": "My docs",
  "base": "/docs/",
  "nav": ["index.md", "guides/"]
}

Options

KeyDefaultWhat it does
title"Docs"Site title and page suffix.
base"/"Path prefix for every link.
navfolder orderSidebar entries, top to bottom.
  • Unknown keys are ignored with a warning.
  • Paths are relative to quill.json.
